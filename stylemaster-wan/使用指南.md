# 视频风格化使用指南（中文）

## 快速开始

StyleMaster 现在支持视频到视频（Video-to-Video, V2V）的风格化转换！

### 一键运行

使用提供的快速启动脚本：

```bash
cd stylemaster-wan

# 使用默认风格图片（浮世绘）
./quick_start_v2v.sh input_videos/my_video.mp4

# 或指定自定义风格图片
./quick_start_v2v.sh input_videos/my_video.mp4 example_test_data/style_images/vangough.png
```

### 详细使用方法

```bash
python inference_v2v_stylemaster.py \
    --input_video <输入视频路径> \
    --style_image <风格参考图片路径> \
    --prompt "视频内容描述" \
    --output_dir ./results_v2v
```

## 支持的视频规格

根据您提供的需求：
- ✅ **帧率**: 30 FPS
- ✅ **时长**: ≤15秒（约450帧）
- ✅ **分辨率**: 360p (640x360) 或更高
- ✅ **计算资源**: 1x A100-80G（完全满足）

## 示例场景

### 场景1：将日常视频转换为浮世绘风格

python inference_v2v_stylemaster.py \

## 参数调优指南

### 1. 控制风格强度

**`style_cfg_scale`** (风格引导强度)
- `2.0-3.0`: 轻微风格化，保留原视频特征
- `4.0-5.0`: 中等风格化（推荐）✨
- `6.0-8.0`: 强烈风格化

**`denoising_strength`** (去噪强度)
- `0.6-0.7`: 轻度改变，保持原视频结构
- `0.8-0.85`: 中度改变（推荐）✨
- `0.9-1.0`: 强度改变，可能显著改变内容

### 2. 平衡质量与速度

**`num_inference_steps`** (推理步数)
- `30-40`: 快速（质量稍低）
- `50`: 平衡（推荐）✨
- `60-80`: 高质量（速度较慢）

### 3. 分辨率选择

针对您的 A100-80G：

| 分辨率 | 显存占用 | 处理帧数 | 适用场景 |
|--------|---------|---------|---------|
| 360x640 | ~20GB | 81-161 | 快速测试 |
| 480x832 | ~30GB | 81 | 标准质量（推荐）✨ |
| 540x960 | ~40GB | 81 | 高质量 |
| 720x1280 | ~60GB | 41-81 | 最高质量 |

### 4. 处理长视频

**方法1：限制帧数**
```bash
# 只处理前3秒（90帧）
python inference_v2v_stylemaster.py \
    --input_video long_video.mp4 \
    --num_frames 89 \  # 会自动调整为89（4n+1）
    --style_image style.jpg \
    --output_dir results_v2v/clip1
```

**方法2：分段处理**

使用 ffmpeg 分割视频：
```bash
# 分割为5秒片段
ffmpeg -i long_video.mp4 -c copy -map 0 -segment_time 00:00:05 -f segment clip_%03d.mp4

# 批量处理
for clip in clip_*.mp4; do
    python inference_v2v_stylemaster.py \
        --input_video "$clip" \
        --style_image style.jpg \
        --output_dir "results_v2v/${clip%.mp4}"
done

# 合并结果
ffmpeg -f concat -safe 0 -i <(for f in results_v2v/*/stylized_video.mp4; do echo "file '$PWD/$f'"; done) -c copy final_output.mp4
```

## 常见问题解决

### Q1: "FileNotFoundError: StyleMaster checkpoint not found"

**解决方案**：先下载模型权重
```bash
python download_ckpt.py
```

### Q2: "CUDA out of memory"（显存不足）

**解决方案**：
1. 降低分辨率：
   ```bash
   --height 360 --width 640
   ```

2. 减少处理帧数：
   ```bash
   --num_frames 41  # 处理更少的帧
   ```

3. 减少推理步数：
   ```bash
   --num_inference_steps 30
   ```

### Q3: 风格化效果不够明显

**解决方案**：增加风格强度
```bash
--style_cfg_scale 6.0 \
--denoising_strength 0.90
```

### Q4: 风格化后丢失了太多原始内容

**解决方案**：降低去噪强度
```bash
--denoising_strength 0.70 \
--style_cfg_scale 3.0
```

### Q5: 视频闪烁或不连贯

**解决方案**：
1. 提供更准确的内容描述（prompt）
2. 增加推理步数：
   ```bash
   --num_inference_steps 60
   ```
3. 使用较低的去噪强度以保持时间连贯性

## 推荐工作流程

### 第一步：快速测试

使用低分辨率和少量帧进行快速测试：

```bash
python inference_v2v_stylemaster.py \
    --input_video test.mp4 \
    --style_image style.jpg \
    --height 360 \
    --width 640 \
    --num_frames 41 \
    --num_inference_steps 30 \
    --output_dir test_output
```

### 第二步：参数调优

基于测试结果调整参数：

```bash
# 如果风格不够明显
--style_cfg_scale 6.0 --denoising_strength 0.90

# 如果内容改变太多
--style_cfg_scale 3.0 --denoising_strength 0.75
```

### 第三步：最终渲染

使用最优参数进行完整处理：

```bash
python inference_v2v_stylemaster.py \
    --input_video final.mp4 \
    --style_image style.jpg \
    --height 480 \
    --width 832 \
    --num_inference_steps 50 \
    --output_dir final_output
```

## 批量处理脚本

创建 `batch_stylize.sh`:

```bash
#!/bin/bash

INPUT_DIR="input_videos"
STYLE_IMAGE="example_test_data/style_images/ukiyoe.jpg"
OUTPUT_BASE="results_v2v"

for video in $INPUT_DIR/*.mp4; do
    name=$(basename "$video" .mp4)
    echo "Processing: $name"
    
    python inference_v2v_stylemaster.py \
        --input_video "$video" \
        --style_image "$STYLE_IMAGE" \
        --prompt "video content" \
        --height 480 \
        --width 832 \
        --num_frames 81 \
        --output_dir "$OUTPUT_BASE/$name" \
        --seed 42
    
    echo "Completed: $name"
done

echo "All videos processed!"
```

运行：
```bash
chmod +x batch_stylize.sh
./batch_stylize.sh
```
